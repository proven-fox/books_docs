# البدء مع Omni Start Soft

لنبدأ بتطبيق ما تعلمناه حتى الآن عن طريق إعداد شركتك في Omni Start Soft.

إذا لم تقم بتحميل Omni Start Soft، يمكنك تحميله من هنا
[muthallathat.com/download](https://muthallathat.com/download).

## إعداد النسخة

عند فتح Omni Start Soft، سيتم عرض خيارين: **ملف جديد** و**ملف موجود**. إذا كانت هذه هي المرة الأولى التي تفتح فيها Omni Start Soft، انقر على **ملف جديد**.

الآن حدد موقعاً مناسباً حيث تريد تخزين الملف وأعطه اسماً.

![ملف جديد](./images/new-file.png)

::: tip موقع الملف
يخزن Omni Start Soft جميع بيانات شركتك ومعاملاتك في ملف `.db` محلي على جهاز الكمبيوتر الخاص بك.

يمكنك تغيير موقع ملف `.db` هذا. إذا قمت بذلك، يمكنك العثور عليه مرة أخرى عن طريق تحديد خيار **ملف موجود**.
:::

الآن، أدخل اسم العمل، البريد الإلكتروني للعمل ومعلومات الدولة. سيساعد هذا في إعداد دليل الحسابات الصحيح بناءً على دولتك.

![معالج الإعداد](./images/setup-wizard.png)

::: tip دليل الحسابات
إذا لم تجد دليل الحسابات لبلدك، يمكنك تحديد **دليل الحسابات القياسي**.
:::

---

تهانينا! لديك الآن شركة تم إعدادها على Omni Start Soft.

يمكنك الآن الانتقال إلى الخطوة التالية لإنشاء بعض القيود الأولية قبل أن تتمكن من البدء في تسجيل فواتيرك ومعاملاتك.
